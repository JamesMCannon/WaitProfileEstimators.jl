# WaitProfileEstimators.jl

Estimators for the Wait & Spies two-parameter exponential D-region electron
density profile (h′, β), given a location and UTC datetime.

Three estimation methods are provided:

- **FIRI fit** — ordinary least squares fit to the Faraday International
  Reference Ionosphere model.
- **McRae & Thomson (2000)** — published polynomial fits in solar zenith angle.
- **Ferguson** — corrected Ferguson empirical model.

## Installation
